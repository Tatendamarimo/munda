# Test images

For testing the photo path when your field doesn't show every problem. Use **Add leaf photo** to pick an image file. Images are downscaled to 1024 px on the device and never uploaded.

**Check each dataset's license on its own page before downloading.** Most are CC BY 4.0, which allows reuse with credit. If an image appears in the demo video, README or Devpost page, credit it (author, dataset, license). Real field footage is preferred for the demo itself.

| Dataset | Covers | Scenarios | Link |
|---|---|---|---|
| KaraAgro AI Maize Dataset (Makerere AI Lab) | Healthy, fall armyworm, maize streak virus; sub-Saharan Africa | 3, 5 | Harvard Dataverse: search "KaraAgro AI Maize Dataset" |
| Labeled Dataset of Healthy and Diseased Maize from Tanzania (NM-AIST / TARI) | Healthy, maize lethal necrosis, maize streak virus | 5, MLN | https://zenodo.org/records/15685236 |
| Maize Nutrient Deficiency Dataset | Nitrogen, phosphorus, potassium, magnesium deficiency, healthy | 1, 6, 7 | https://data.mendeley.com/datasets/34gb2gr7p2 |
| Nitrogen deficiency in maize (Data in Brief, 2023) | Canopy images at three nitrogen levels | 1 | https://data.mendeley.com/datasets/g7xnn2bm4g |
| Multi-format Maize Leaf Image Dataset (Bangladesh, 2026) | Leaf blights, rust, grey leaf spot, streak and more | 8 | https://data.mendeley.com/datasets/sb4wwjs8bz |
| Field images of maize annotated with disease symptoms (Wiesner-Hanks et al.) | Northern leaf blight, field conditions | 8 (blight look-alike) | https://doi.org/10.1186/s13104-018-3548-6 |

No dataset here covers waterlogging, drought rolling, sulfur, zinc or striga well. Use descriptions only for those scenarios, which matches how Munda is meant to work: the farmer's words and answers carry the assessment, and the photo is supporting evidence.
