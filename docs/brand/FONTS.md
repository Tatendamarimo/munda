- **Bricolage Grotesque**: Copyright 2022 The Bricolage Grotesque Project Authors. Web: `@fontsource-variable/bricolage-grotesque`. Android: `res/font/bricolage_bold.ttf`, an instance of the variable font at weight 700.
- **Atkinson Hyperlegible Next**: Copyright 2024 Braille Institute of America, Inc. Web: `@fontsource/atkinson-hyperlegible-next`. Android: `res/font/atkinson_regular.ttf` and `atkinson_bold.ttf`, converted from the same WOFF2 files.

The OFL allows bundling these fonts with the app. The Android copies were converted and instanced, not changed in design.
